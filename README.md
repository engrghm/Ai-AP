# আমার সহকারী — ব্যক্তিগত এআই অ্যাসিস্ট্যান্ট (Android)

একটি অ্যান্ড্রয়েড অ্যাপ: আপনি শুধু মুখে বলবেন, বাকিটা সে নিজেই বুঝে গুছিয়ে রাখবে।

- 🎤 **মুখে বললেই অটো-নোট**: মাইকে বলা শেষ হলেই পাঠিয়ে দেয়। একটা কথায় কয়েকটা জিনিস থাকলে প্রতিটা আলাদা করে ঠিক জায়গায় রাখে। অ্যাপ আইকনে লং-প্রেস করে **"মুখে বলুন"** শর্টকাট থেকে সরাসরি বলা শুরু করা যায়।
- 🧠 **সব গুছিয়ে মনে রাখে**: ব্যক্তিগত তথ্য, পরিবার, কাজ, স্বাস্থ্য, টাকা-পয়সা, লক্ষ্য, যোগাযোগ, আইডিয়া, নোট, সব ক্যাটাগরি অনুযায়ী।
- 📋 **নিজে থেকেই লিস্টে তোলে**: "দুধ কিনতে হবে" বললে কেনাকাটায়, "রিপোর্ট জমা দিতে হবে" বললে করণীয় লিস্টে।
- ⏰ **সময়মতো মনে করায়**: একবার, প্রতিদিন, সপ্তাহে, মাসে বা প্রতি বছর (জন্মদিন, বার্ষিকী)। বিল বা অ্যাপয়েন্টমেন্টের আগের দিনও নিজে থেকে মনে করায়। নোটিফিকেশনেই **"হয়ে গেছে"** আর **"১০ মিনিট পরে"** বাটন।
- 💰 **খরচের হিসাব**: "আজ বাজারে ৮৫০ টাকা" বললেই লিখে রাখে; মাসের মোট, ক্যাটাগরি অনুযায়ী খরচ, আয়।
- 🔥 **অভ্যাস ট্র্যাকার**: নামাজ, হাঁটা, বই পড়া, ওষুধ… প্রতিদিনের টিক, টানা কত দিন হলো।
- 📞 **ফোনের কাজ এক ট্যাপে**: "আম্মুকে ফোন দিতে হবে" বললে কল বাটন; এ ছাড়া SMS, WhatsApp, ইমেইল, ম্যাপে জায়গা, ক্যালেন্ডারে ইভেন্ট, অ্যালার্ম। আপনি ট্যাপ না করা পর্যন্ত কিছুই হয় না।
- 🌐 **ইন্টারনেট থেকে তথ্য**: দাম, খবর, নামাজের সময়, কীভাবে করবেন ইত্যাদি খুঁজে দেয়।
- 🌅 **সকালের পরিকল্পনা ও 🌙 রাতের হিসাব**: প্রতিদিন নোটিফিকেশনে। সকালে আজকের কাজ ও ফোকাস, রাতে কী হলো, কী বাকি, কত খরচ হলো।
- 🔊 **উত্তর পড়ে শোনায়** (সেটিংসে চালু করুন)।
- 💾 **ব্যাকআপ**: সব তথ্য একটা ফাইলে সংরক্ষণ করুন, নতুন ফোনে ফিরিয়ে আনুন।

ব্রেইন হিসেবে Claude (Anthropic) ব্যবহার করা হয়েছে। আপনার সব তথ্য থাকে আপনার ফোনেই (অ্যাপের নিজস্ব ডাটাবেসে)।

## APK কীভাবে পাবেন

এই রিপোতে GitHub Actions আছে, যা প্রতিবার `android/` ফোল্ডারে পরিবর্তন push হলে নিজে থেকেই APK বানায়।

1. GitHub-এ রিপোর **Releases** অংশে যান। সবচেয়ে নতুন `আমার সহকারী — বিল্ড N` থেকে `AiAP-N.apk` ফোনে ডাউনলোড করুন।
   (অথবা **Actions → Build Android APK → সর্বশেষ রান → Artifacts** থেকে।)
2. ফোনে APK খুলুন। "Unknown sources / অজানা উৎস থেকে ইনস্টল" অনুমতি চাইলে দিন।
3. অ্যাপ খুলে **সেটিংসে** আপনার নাম আর Claude API key দিন। API key পাবেন <https://console.anthropic.com> থেকে।
4. নোটিফিকেশনের অনুমতি দিন। রিমাইন্ডার ট্যাবে "Alarms & reminders" অনুমতি চাইলে সেটাও দিন, তাহলে রিমাইন্ডার একদম ঠিক সময়ে আসবে।

### নিজে বিল্ড করতে চাইলে

Android Studio দিয়ে `android/` ফোল্ডারটি খুলে Run চাপুন। অথবা:

```bash
cd android
./gradlew :app:assembleDebug      # APK: app/build/outputs/apk/debug/app-debug.apk
```

## প্রজেক্ট কাঠামো

```
android/
  core/   Claude এর সাথে কথা বলা, টুল (মেমোরি, লিস্ট, রিমাইন্ডার); খাঁটি Kotlin, টেস্টসহ
  app/    অ্যান্ড্রয়েড অ্যাপ: স্ক্রিন, SQLite ডাটাবেস, অ্যালার্ম ও নোটিফিকেশন, সকালের ব্রিফিং
assistant/, main.py   কম্পিউটার/টেলিগ্রাম ভার্সন (Python), নিচে দেখুন
```

শুধু `core` বিল্ড ও টেস্ট করতে Android SDK লাগে না: `cd android/core && gradle test`

## কম্পিউটার / টেলিগ্রাম ভার্সন (Python)

একই সহকারী টার্মিনালে বা টেলিগ্রাম বট হিসেবেও চালানো যায়:

```bash
pip install -r requirements.txt
cp .env.example .env     # ANTHROPIC_API_KEY ও নাম দিন
python main.py           # টার্মিনালে চ্যাট
python main.py telegram  # টেলিগ্রাম বট (.env এ TELEGRAM_BOT_TOKEN দিন)
```

মনে রাখবেন: Python ভার্সনের ডাটাবেস আর অ্যান্ড্রয়েড অ্যাপের ডাটাবেস আলাদা।

## নিরাপত্তা

- API key আর আপনার সব তথ্য শুধু আপনার ফোনে থাকে। তবে উত্তর তৈরির জন্য মেসেজগুলো Anthropic API-তে পাঠানো হয়।
- পাসওয়ার্ড, পিন বা পুরো কার্ড/অ্যাকাউন্ট নম্বর সহকারীকে দেবেন না; সে এগুলো সংরক্ষণ করবে না।
- APK টি আপনার ব্যক্তিগত ব্যবহারের জন্য debug key দিয়ে সাইন করা।
