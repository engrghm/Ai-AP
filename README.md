# Ai-AP — আমার ব্যক্তিগত এআই অ্যাসিস্ট্যান্ট

একটি ব্যক্তিগত এআই সহকারী, যে:

- 🧠 **সবকিছু মনে রাখে** — আপনার তথ্য, পরিবার, কাজ, স্বাস্থ্য, লক্ষ্য, পছন্দ; আপনি যা বলবেন নিজে থেকেই সংরক্ষণ করে
- 📋 **লিস্ট রাখে** — টুডু, শপিং, গোল, বই, আইডিয়া… যেকোনো নামের লিস্ট
- ⏰ **সময়মতো মনে করিয়ে দেয়** — একবার, প্রতিদিন, প্রতি সপ্তাহে বা প্রতি মাসে
- 🌅 **প্রতিদিন সকালে গাইড করে** — আজকের রিমাইন্ডার, বাকি কাজ, আর কোন ৩টা কাজে ফোকাস করবেন
- 💬 **বাংলায় কথা বলে** — টার্মিনালে অথবা মোবাইলে টেলিগ্রামে

ব্রেইন হিসেবে Claude (Anthropic) ব্যবহার করা হয়েছে; আপনার সব তথ্য থাকে আপনার নিজের কম্পিউটারের একটি SQLite ফাইলে (`data/assistant.db`)।

## সেটআপ

```bash
git clone <এই রিপো>
cd Ai-AP
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # তারপর .env ফাইলে API key ও নাম দিন
```

`ANTHROPIC_API_KEY` পাবেন <https://console.anthropic.com> থেকে।

## ব্যবহার

### ১) টার্মিনালে চ্যাট

```bash
python main.py
```

যতক্ষণ চালু থাকবে, রিমাইন্ডার সময়মতো টার্মিনালে চলে আসবে।
কমান্ড: `/briefing` (আজকের গাইডলাইন), `/reset` (নতুন কথোপকথন), `/exit`

### ২) টেলিগ্রাম বট (মোবাইলে রিমাইন্ডার পেতে — সুপারিশকৃত)

1. টেলিগ্রামে **@BotFather** → `/newbot` → টোকেন কপি করে `.env` এ `TELEGRAM_BOT_TOKEN` দিন
2. `python main.py telegram` চালান, বটকে `/start` পাঠান — সে আপনার chat ID দেখাবে
3. সেই আইডি `.env` এ `TELEGRAM_OWNER_CHAT_ID` তে দিন, বট রিস্টার্ট করুন

শুধু আপনার chat ID থেকে আসা মেসেজের উত্তর দেবে — অন্য কেউ আপনার তথ্য দেখতে পারবে না।
২৪ ঘণ্টা রিমাইন্ডার পেতে বটটি এমন কোথাও চালু রাখুন যা সবসময় অন থাকে (যেমন একটি ছোট VPS, Raspberry Pi, বা সবসময় চালু থাকা পিসি)।

## উদাহরণ

```
আপনি> আমার নাম মাসুম, আমি ঢাকায় থাকি। আমার স্ত্রীর জন্মদিন ১২ মার্চ।
সহকারী> মনে রাখলাম ✅ — চাইলে প্রতি বছর ১১ মার্চ মনে করিয়ে দিতে পারি।

আপনি> শপিং লিস্টে দুধ, ডিম আর চাল যোগ করো
আপনি> প্রতিদিন রাত ১০টায় ওষুধ খাওয়ার কথা মনে করাবে
আপনি> কাল সকাল ১১টায় অফিসে মিটিং আছে, ১ ঘণ্টা আগে মনে করিও
আপনি> আমার এই বছরের লক্ষ্য: ১০ কেজি ওজন কমানো, ১২টা বই পড়া
আপনি> আজকে কী কী করা উচিত?
আপনি> আমার শপিং লিস্টে কী আছে?
```

## প্রজেক্ট কাঠামো

| ফাইল | কাজ |
|---|---|
| `main.py` | চালু করার জায়গা (`cli` / `telegram` / `briefing`) |
| `assistant/brain.py` | Claude এর সাথে কথা বলা, টুল চালানো, ব্রিফিং |
| `assistant/tools.py` | মেমোরি, লিস্ট আর রিমাইন্ডারের টুলগুলো |
| `assistant/db.py` | SQLite ডাটাবেস (আপনার সব তথ্য) |
| `assistant/scheduler.py` | সময় হলে রিমাইন্ডার ও সকালের ব্রিফিং পাঠানো |
| `assistant/telegram_bot.py` | টেলিগ্রাম বট |
| `tests/` | অফলাইন টেস্ট (`python -m pytest`) |

## সেটিংস (`.env`)

| নাম | মানে |
|---|---|
| `OWNER_NAME` | আপনার নাম |
| `TIMEZONE` | টাইমজোন (ডিফল্ট `Asia/Dhaka`) |
| `BRIEFING_TIME` | সকালের ব্রিফিংয়ের সময়, যেমন `08:00` (ফাঁকা = বন্ধ) |
| `DB_PATH` | ডাটাবেস ফাইলের লোকেশন |
| `CLAUDE_MODEL` | ঐচ্ছিক; ডিফল্ট `claude-opus-5-5` |

## নিরাপত্তা

- `data/assistant.db` ও `.env` গিটে যায় না (`.gitignore`); নিয়মিত `data/` ফোল্ডারের ব্যাকআপ রাখুন।
- পাসওয়ার্ড, পিন বা পুরো কার্ড/অ্যাকাউন্ট নম্বর অ্যাসিস্ট্যান্টকে দেবেন না — সে এগুলো সংরক্ষণ করবে না।
- আপনার মেসেজ উত্তর তৈরির জন্য Anthropic API তে পাঠানো হয়।
